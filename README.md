A tiny program for the [One Word, First Thought](https://make.fun/c/u-0xkianno-one-word-first-thought-106abaf8) bounty on make.fun: it writes a single word — "snollygoster", 19th-century American slang for a shrewd, unscrupulous person (especially a politician) — to `entry.txt`. A word that sounds like a creature from a children's book but bites like an insult: surprising, vivid, and witty on a second look.

Run it with Node 22+:

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
